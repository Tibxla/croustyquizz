# Labels de tri

Les skills raisonnent avec cinq rôles de tri canoniques. Ce fichier associe chaque rôle au label réellement utilisé dans les issues de ce dépôt.

| Label dans mattpocock/skills | Label dans nos issues | Sens                                              |
| ---------------------------- | --------------------- | ------------------------------------------------- |
| `needs-triage`               | `needs-triage`        | Un mainteneur doit évaluer l'issue                |
| `needs-info`                 | `needs-info`          | En attente d'informations de la part de l'auteur  |
| `ready-for-agent`            | `ready-for-agent`     | Spécifiée à fond, un agent peut la prendre seul   |
| `ready-for-human`            | `ready-for-human`     | À implémenter par un humain                       |
| `wontfix`                    | `wontfix`             | Ne sera pas faite                                 |

Quand un skill mentionne un rôle (par exemple « poser le label de tri prêt pour un agent »), utiliser le label correspondant de la table.

Modifier la colonne de droite si le vocabulaire des labels change.
